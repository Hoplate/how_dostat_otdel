# Игровые изображения

`game/assets/characters/{dima,lena,marina,pasha}.webp` — четыре изображения
с прозрачным фоном. Внешность Димы основана на предоставленных пользователем
референсах. Визуальный материал для единого состава получен генерацией и
подготовлен как набор отдельных игровых спрайтов. Это не библиотека 3D-моделей.

Лена: тёмные волосы и строгая офисная одежда. Марина: каштановые волосы,
тёплый кардиган, меньший рост. Паша: борода, полная фигура, жёлтые очки.
Разницу роста задаёт OfficeCatalog.HEIGHTS, а не размер исходного файла.

Предметы, мебель, свет и стены создаются скриптом world.gd из примитивов Godot.
Звуки синтезируются программно. Отдельных шрифтовых файлов в проекте нет;
используется встроенное оформление интерфейса движка.

Для замены персонажа: сохраните прозрачную WEBP-текстуру с ногами у нижнего
края изображения и замените соответствующий файл. Для полноценной 3D-модели
следует заменить визуальную часть OfficeActor; навигацию и игровые правила
менять не требуется.
